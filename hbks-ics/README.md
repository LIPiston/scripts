# hbks-ics

油猴脚本：在河北科技师范学院教务系统课表页面添加“导出 ICS”按钮。

## 使用

1. 在 Tampermonkey 新建脚本，粘贴 `hbks-ics.user.js`。
2. 打开教务系统的实际课表页面并刷新。
3. 点击右下角“导出 ICS”。
4. 首次导出输入第 1 周周一日期，格式为 `YYYY-MM-DD`。
5. 将下载的 ICS 导入 Outlook 的独立课表日历。

ICS 中每个事件包含一个提前 30 分钟的显示提醒，目标日历名称为：

`我的课表 2026-2027第1学期`

## 当前适配情况

已针对 `我的课表.html` 的教务系统域名和 `Cell{weekday}{period}` 课表单元格式编写。脚本会优先读取当前页面及同源 iframe 中的 Cell 单元；找不到时回退到普通表格行列解析。

## 注意

- 第 1 周周一日期和节次时间必须与学校实际安排一致；脚本默认使用当前课表导入时的节次时间，需要变更时编辑脚本顶部 `CONFIG.periods`。
- 当前保存的 HTML 是外层框架页，未包含登录后动态加载的实际课表 iframe 内容，因此对离线 HTML 的完整事件数量无法在本机确认。应在登录后的实际课表页面运行。
- 若实际课表位于跨域 iframe，浏览器安全策略不允许父页面读取内容；请在 iframe 对应的课表页面运行脚本，或把实际课表页面的 URL 加入 `@match`。
